Can it run GTA VI on PC?

Grand Theft Auto VI for Xbox Series, build 1.0.2.1 · status as of 23 November 2026

Not yet.

The game's executable (game_scarlett_master.exe) is missing from the package studied, so the game itself has never been started, by AnyXboxX or by Leonida. Once an executable is available, expect at least a few weeks of work before the game is even minimally playable.

Disk space to plan for

~30 GB
To run the game

Leonida's check, shaders and runtime stages.

~370 GB
Asset export (optional)

Only for the asset tools (models, textures, audio). Not needed to play.

~400 GB
Full build

All stages. Figures are as Windows Explorer shows them (GiB): 400 GiB is about 430 GB.

These are work files, on top of the game package itself, which the runtime reads in place. Source: the prerequisites in Leonida's README. Work folders can go on another drive.

What you will need, once it works

  • Your own copy of the Xbox Series package, version 1.0.2.1. Nothing here provides it or explains how to get it.
  • Windows 10 or 11, 64-bit, and a GPU with Vulkan.
  • The disk space above.
